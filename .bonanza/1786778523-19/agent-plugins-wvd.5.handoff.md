# agent-plugins-wvd.5 handoff

Caveat: the profile→Gherkin bridge is `corpus.vocabulary` (unexported, `cli/core/corpus/features.go`) — VTAG/VCON/QRY reach the compiled patterns through `newVocabulary(profile.FeatureTags())`, the fence info strings through `gherkin.FenceTags()` (GREF's mask must read that, not a literal), a feature's code through `featureCodeOf` (last-but-one dash segment of the matched identifier, never a named capture), and Gherkin parse failures through the new `Corpus.FeatureFailures() []SourceFailure`, which is populated by a cold build only and is empty for a warm corpus, so VCON must recompute `gherkin/parse` the way `duplicateSlugs` is recomputed in `fromIndex`; note also that the input-hash construction version moved to `2` and every `cli/testdata/cases/*/expected/manifest.json` hash was regenerated.
