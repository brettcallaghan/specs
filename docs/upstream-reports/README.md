# Upstream reports

Defects in this project's **third-party dependencies**, written up ready to
post to whoever maintains them.

**Not `.sf/outbox/`.** That directory carries issues about skills *this
repository vends*, addressed to whoever vends them. These are the other
direction: issues we found in software we depend on, addressed outward.

**Nothing here is filed automatically.** Posting to a third party's tracker is
an outward-facing act, so a human posts it. Each file is complete enough to
paste as-is.

**Each is verified against the installed version before it is written**, and
records the reproduction it actually ran — not the one that produced the
original observation. A report of a defect the maintainer cannot reproduce
costs them more than it costs us.
