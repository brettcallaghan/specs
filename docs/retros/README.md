# Retros

One document per `bead-bonanza` run, written by `sprint-retro` at the end of
it: the results, every finding the run captured verbatim, the routing, the
validation evidence, and what the run could not verify. `log.md` beside them
carries one row per run.

The directory is `sf.toml`'s `[reports] dir`, and each run's record is recorded
on its run epic as `metadata.findings_path`, so `bd show <run-epic>` finds it
from the epic id alone.

Records from before 2026-08-25 are under `docs/research/sprint-findings/`.
